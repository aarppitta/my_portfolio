# Arpita Chaudhari — Portfolio

Premium dark-mode editorial portfolio. Vite + React + Tailwind + Framer Motion.

## Run

```bash
npm install
npm run dev
```

Build / preview:

```bash
npm run build
npm run preview
```

## Customize before deploying

Search for `TODO` — there are four placeholders to swap in:

1. `src/data/profile.js` → `github`, `linkedin`, `formspreeId`, `resumeUrl`
2. `src/data/projects.js` → real GitHub repo URLs
3. Drop your résumé PDF into `public/Arpita-Chaudhari-Resume.pdf`
4. (Optional) Add an Open Graph image at `public/og-image.png`

## Deploy

Works out of the box on Vercel / Netlify. Build command `npm run build`, output `dist`.
